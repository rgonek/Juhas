---
name: juhas-review-response
description: Use when addressing code-review feedback or explaining fixes made in response to review comments.
---

Identify each concern by the relevant function, class, component, configuration key, or short code excerpt. Add the file path when needed to disambiguate. Briefly restate the concern and explain the fix or why no change is needed. Use actual names from the source; quote only the smallest fragment needed to understand the outcome. Each response should be understandable without looking up line numbers.
